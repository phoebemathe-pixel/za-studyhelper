# 🔮 ZA Study Helper SA

**Study during loadshedding! Works OFFLINE - No wifi, no data, no API key needed!**

> Paste messy notes + learning outcomes → Get exam-ready Summary + Definitions + Quiz + PDF

### 🚀 Live App:
**https://za-studyapper.streamlit.app**

### ✨ Features
- **🔋 OFFLINE Mode V11:** Works with NO internet! Anti-repeat logic, answers each outcome with 4 bullets from YOUR notes only
- **🤖 ONLINE Mode:** Uses Gemini AI for smarter packs (optional key)
- **📄 PDF Download:** Save pack before lights go off
- **🇿🇦 Built for SA students**

### 📖 How to use (No key needed!)
1. Open the live link
2. Leave Gemini Key box EMPTY (for offline)
3. Paste notes + Learning Outcomes
4. Click Generate → Download PDF

### 🔑 Want Online Mode?
Get free key: https://aistudio.google.com/app/apikey → paste in box
